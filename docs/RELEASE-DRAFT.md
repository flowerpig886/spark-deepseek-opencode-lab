# 首次 Release 文案草稿

建议标题：`v0.1.0-preview — 双 Spark DeepSeek + OpenCode 实测报告`

这是我们首次整理的双 DGX Spark 本地编程自动化报告，记录固定配置、缓存修改、真实 OpenCode 后端工具调用以及所有失败。

主要观察：

- DeepSeek-V4.1-Flash-1017 EXL3 2.9bpw，TensorFold TP2，单并发、low、32768输出上限。
- 三道新 pydicom 题各跑两次，补丁及完整任务均4/6；两次失败都漏了同一边界要求。
- 连续65分钟、706请求、687工具调用，无异常结束或热限频标志。
- 两种基础恢复流程可继续会话，但恢复后修复仅1/2正确；实际生产修改后的检查点恢复仍未验证。

适合把它作为配置参考和带独立验证的自动化起点，不作为无人值守可靠性证明。当前提供文档、数字结果、基础接入模板及固定版本缓存修改准备脚本；没有附带完整项目专用评测插件、模型或镜像。

下一版本可补充实际修改检查点、更多仓库及可移植的完整复现工具。原有失败记录会继续保留。

发布前确认作者署名、LICENSE和可见性；本文件仅为草稿，不代表已创建Release。
